MySQL Assignment 2 – Querying Data

Project Overview

This assignment focuses on querying and retrieving data from a MySQL database. It is a continuation of MySQL Assignment 1, where the database and tables were created using SQL constraints.

The employee database contains three tables:

Employees

Departments

Location

Employee data was inserted into the tables using the provided DML queries. Various SQL commands were then used to retrieve, filter, sort, group, and analyze the data.
